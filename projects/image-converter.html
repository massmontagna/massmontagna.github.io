Image File Conversion Tool

A small Python tool that converts images from one format to another using your system's native file picker, on both macOS and Windows.

01 / overview

Convert images without leaving your desktop

Converting a handful of images shouldn't need an online upload or a heavyweight editor. This tool opens the familiar Finder or File Explorer picker, lets you choose one or more images, and writes them out in the format you ask for.

It is built on Pillow, with pillow-heif adding support for HEIC photos from iPhones.

02 / how it works

Pick, choose a format, done

  1. 01

    Select images

    A native file picker opens so you can choose one or more images.

  2. 02

    Choose a format

    Type the output format. Supported types are JPEG, PNG, BMP, TIFF, WEBP, HEIC and GIF.

  3. 03

    Convert

    Each image is converted and saved next to the original, with the correct file extension added automatically.

03 / features

What it does

  • Native file picker on macOS and Windows
  • Batch conversion of multiple images at once
  • Supports JPEG, PNG, BMP, TIFF, WEBP, HEIC and GIF
  • Output saved alongside the originals
  • Exits with a clear error message if an unsupported format is entered

04 / run it

Try it yourself

You need Python 3.7 or later. Install the dependencies (Pillow and pillow-heif) and run the script.

git clone https://github.com/massmontagna/Image-Converter
cd Image-Converter
pip install -r requirements.txt

python image_converter_tool.py
