Formula 1 Grand Prix Predictions

A machine learning tool that predicts Formula 1 race results from qualifying data, combining a Random Forest and a neural network into one ensemble.

01 / overview

Predicting the race from the grid

Qualifying says a lot about how a Grand Prix will go, but not everything. This project asks how far historical data can take a prediction: given the qualifying session for a race, can a model estimate the finishing order?

It pulls session data from the FastF1 API, trains two different models on seasons from 2018 to 2023, and blends their output into a single set of predictions for any circuit and year.

02 / how it works

From raw timing data to a predicted finishing order

  1. 01

    Gather data

    data_gathering.py fetches historical qualifying, race and weather data through FastF1 and stores it locally.

  2. 02

    Preprocess

    data_preprocessing.py cleans the data and encodes drivers and teams, so the models can handle changing line-ups across seasons.

  3. 03

    Train two models

    model_training.py trains a Random Forest as a simple baseline and a neural network, saving both along with their preprocessors.

  4. 04

    Predict

    predict.py asks for a year and race name, fetches that qualifying session, and combines both models into an ensemble prediction.

03 / features

What it does

  • Data gathering from the FastF1 API
  • Two models: Random Forest and a deep learning network
  • Ensemble predictions combining both models
  • Works across different circuits and years
  • Weather data included in the predictions
  • Driver and team encoding that copes with changing line-ups
  • Trained models are saved and reusable

04 / run it

Try it yourself

Clone the repository, install the requirements, then run the four scripts in order. The last one prompts for a year and a race name such as “Monaco Grand Prix”.

git clone https://github.com/massmontagna/GrandPrix-Predictions
cd GrandPrix-Predictions
pip install -r requirements.txt

python data_gathering.py
python data_preprocessing.py
python model_training.py
python predict.py
